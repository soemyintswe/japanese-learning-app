# Japanese Learning & Dictionary App

A mobile application built with React Native and Expo for learning Japanese, featuring a multi-language dictionary (Japanese, English, Myanmar), a weekly study planner, a note-taking section, and role-based administration for teachers to upload lessons.

## Features
- **Multi-language Dictionary:** Search vocabulary in Japanese, English, and Myanmar with CRUD operations.
- **Weekly Study Planner:** Track daily study tasks (Vocabulary, Kanji, Grammar, Listening, Reading).
- **Notes Section:** Jot down personal study notes.
- **Resources:** Quick access to helpful Japanese learning apps and YouTube channels.
- **Admin Access:** Secure teacher authentication via Gmail to manage and upload lessons.

## Tech Stack
- React Native / Expo
- Firebase Authentication & Firestore
- React Navigation
